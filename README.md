# DailyMart QA

Учебный QA-проект по функциональному тестированию регистрации пользователя веб-сайта DailyMart.

## О проекте

В рамках проекта проведено тестирование функциональности регистрации пользователя на основании требований.

Выполнены анализ требований, подготовка тестовой документации, функциональное тестирование, регистрация обнаруженных дефектов в Jira, рповторное тестирование исправлений и регрессионное тестирование.

## Объект тестирования

Функциональность регистрации пользователя DailyMart.

## Виды тестирования

- Функциональное тестирование
- повторное тестирование исправленных дефектов
- Регрессионное тестирование

## Тестовая документация

В ходе проекта были подготовлены:

- чек-лист;
- тест-кейсы;
- баг-репорты;
- чек-лист регрессионного тестирования;
- отчет о тестировании (Test Report).

## Инструменты

- Jira — работа с требованиями, ведение тестовой документации и баг-репортов
- Google Chrome — выполнение тестирования
- GitHub — хранение материалов проекта и представление портфолио
