# DailyMart QA

Учебный QA-проект по функциональному тестированию регистрации пользователя веб-сайта DailyMart.

## О проекте

DailyMart — веб-сайт интернет-магазина. В рамках проекта проведено тестирование функциональности регистрации пользователя на основании предоставленных требований.

Проект включал анализ требований, разработку тестовой документации, функциональное тестирование, работу с дефектами, ретестирование исправлений и регрессионное тестирование.

## Цель тестирования

Проверить функциональность регистрации пользователя DailyMart на соответствие проанализированным требованиям и выявить дефекты до релиза продукта.

## Область тестирования

В рамках проекта тестировалась функциональность регистрации пользователя:

- форма регистрации;
- валидация поля «Имя»;
- валидация поля «Email»;
- валидация поля «Пароль»;
- обязательность принятия Условий использования и Политики конфиденциальности;
- отправка формы регистрации;
- сообщения валидации и сообщение об успешной регистрации;
- поведение системы после успешной регистрации.

## Выполненная работа

В ходе проекта были выполнены:

- анализ и уточнение требований;
- разработка чек-листа;
- разработка тест-кейсов;
- функциональное тестирование;
- оформление обнаруженных дефектов в Jira;
- ретестирование исправленных дефектов;
- определение области регрессионного тестирования;
- проведение регрессионного тестирования;
- составление итогового Test Report.

## Результаты тестирования

| Показатель | Результат |
|---|---:|
| Выполнено тест-кейсов | 6 |
| Выявлено дефектов при первоначальном функциональном тестировании | 18 |
| Дополнительно выявлено дефектов при регрессионном тестировании | 1 |
| Всего выявлено дефектов | **19** |
| Исправлено и закрыто | **19** |
| Открытых известных дефектов | **0** |

После предоставления исправленных сборок проводилось ретестирование дефектов и регрессионное тестирование. Часть дефектов потребовала нескольких итераций исправления.

В ходе регрессионного тестирования дополнительно был выявлен дефект BR-019.

По итогам финального ретестирования и регрессионного тестирования все выявленные дефекты были исправлены и закрыты.

## Ограничения тестирования

Тестирование проводилось в одном тестовом окружении.

Кроссбраузерное и кроссплатформенное тестирование не проводилось.

Область тестирования была ограничена функциональностью регистрации пользователя.

## Итог

В рамках проекта выполнен цикл функционального тестирования регистрации пользователя: от анализа требований и подготовки тестовой документации до выявления дефектов, ретестирования исправлений и проведения регрессионного тестирования.

По результатам финального ретестирования и регрессионного тестирования все выявленные дефекты были исправлены и закрыты. Известные открытые дефекты отсутствуют.
