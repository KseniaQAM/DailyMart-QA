# Functional Testing Checklist — DailyMart

Функциональный чек-лист тестирования регистрации пользователя веб-сайта DailyMart.

**Статусы:**
- `Passed` — проверка пройдена успешно;
- `Failed` — выявлено несоответствие требованиям;
- `BR-XXX` — идентификатор соответствующего баг-репорта в Jira.

## Результаты выполнения чек-листа

В ходе функционального тестирования регистрации пользователя были проверены:

- основной сценарий регистрации;
- обязательность полей;
- валидация имени;
- валидация email;
- валидация пароля;
- граничные значения;
- обработка некорректных входных данных;
- элементы интерфейса и сообщения валидации;
- поведение системы после успешной регистрации.

Выявленные несоответствия были зарегистрированы в Jira в виде баг-репортов и переданы на исправление.

После предоставления исправленных сборок было выполнено ретестирование дефектов и регрессионное тестирование.
