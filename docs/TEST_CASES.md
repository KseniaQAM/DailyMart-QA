# Test Cases — DailyMart

Тест-кейсы для проверки функциональности регистрации пользователя веб-сайта DailyMart.

---

## TC-REG-001 — Регистрация с корректными данными

**Priority:** High  
**Status:** Passed

### Preconditions
1. Пользователь находится на странице регистрации.
2. Используемый для регистрации email не зарегистрирован в системе.

### Steps
1. Ввести имя из Test Data в поле «Имя».
2. Ввести email из Test Data в поле «Email».
3. Ввести пароль из Test Data в поле «Пароль».
4. Установить флажок «Я принимаю Условия использования и Политику конфиденциальности».
5. Нажать кнопку «Зарегистрироваться».

### Test Data
- Имя: Алла
- Email: allatest@example.com
- Пароль: пароль123

### Expected Result
1. Отображается сообщение «Регистрация успешно завершена».
2. Пользователь автоматически авторизуется.
3. Выполняется переход на главную страницу DailyMart.
4. В интерфейсе отображается имя зарегистрированного пользователя «Алла».
